# Проверка сборки

Проверено 14 октября 2026 года на macOS / Apple Silicon, Python 3.12.14.

| Проверка | Результат |
|---|---|
| Установка `scripts/bootstrap.py` в новое `.venv` | Успешно, включая создание окружения без ensurepip |
| `pip check` | Несовместимые зависимости не обнаружены |
| Аудит пакетов | `openai`, `tiktoken`, NVIDIA-пакетов нет |
| Автотесты ядра, провайдера, Flask и Streamlit AppTest | 30 тестов прошли |
| Реальный OCR PNG и сканированного PDF | Контрольные русские слова и числа распознаны |
| Реальный E5-поиск без совпадения ключевых слов | Нужный документ на первом месте |
| Запуск Flask + Streamlit командой `manage.py run` | Оба сервера запущены, интерфейс проверен в браузере |
| Поиск через браузер | Получены фрагменты двух тестовых документов |
| Остановка Ctrl+C | Оба сервера завершены, оба порта освобождены |

Снимок настоящего интерфейса: [interface.png](interface.png).

Для OCR использован Tesseract 5.5.3 с rus/eng и Poppler; для поиска — локальная ревизия E5, указанная в config.example.json. Проверки выполнялись в отдельных временных базах без пользовательских документов.

**Предел проверки:** новый живой вызов генерации GigaChat не выполнялся — ключ пользователя отсутствует в тестовой среде. OAuth, ошибки API, обновление токена, ответы и проверка цитат покрыты тестами с подставными ответами. Проверка аккаунта после установки: `manage.py doctor --live`, затем вопрос в чате. Конфигурация F5 подготовлена по документации debugpy; взаимодействие с самим VS Code Debugger в этой проверке не выполнялось. Linux и Intel Mac не проверялись.

## Дополнение к проверке от 14 октября 2026 года

Выпуск `document-rag-vscode-tested` дополнительно прошёл 37 автотестов и испытание на 50 файлах с двумя ГОСТ, PDF, DOCX и сканами. Детальные метрики, исправления, границы проверки и команды повторения находятся в `evaluation/REPORT.md` и `evaluation/README.md`. Предыдущая таблица выше описывает базовую сборку; живые ответы GigaChat в новом испытании также не проверялись.
