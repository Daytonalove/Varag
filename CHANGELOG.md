# История изменений Варяга

## 2026-10-16 — Fast RAG v6 и единый запуск

### Изменения

- Обычный чат доступен без загрузки документов. Ответы из общих знаний
  обозначаются отдельно от ответов с документальными источниками.
- Fast RAG возвращает обычный текст со ссылками вместо обязательного JSON.
  Проверки ссылок, точных кодов мер и чисел сохранены.
- Исправлена потеря ответов из-за нумерации Markdown-списков: номера пунктов
  больше не считаются фактическими числами из документа.
- Короткие вопросы используют компактную выборку; большие наборы документов
  по-прежнему могут использовать расширенный контекст выбранной модели.
- Для резюме выбираются фрагменты из разных частей документа. Полный охват
  документа не гарантируется и обозначается в ответе.
- При отказе GigaChat найденные источники остаются доступны. Для заблокированного
  резюме выводится явно подписанная локальная подборка выдержек.
- Отказ фильтра или достижение лимита ответа больше не блокирует другие вопросы
  через механизм временного отключения недоступного провайдера.
- Единый запуск `.venv/bin/python manage.py bank` использует настроенную базу
  `bank.database`. Другую рабочую копию можно перенаправить через `bank.workspace`.
  Интерфейс по умолчанию: `http://127.0.0.1:8502/`.

### Проверки

- 169 локальных тестов прошли: `python -m unittest discover -s tests -q`.
- Живой запрос к GigaChat-2 о таблицах сегментации и межсетевого экранирования
  получил ответ со ссылками на таблицы 13 и 42.
- Проверены общий чат и ответ об отсутствии нужной информации в выборке ГОСТа.

### Известные ограничения

- GigaChat продолжает блокировать резюме проверенного пользовательского ГОСТа.
  Локальные выдержки не являются смысловым резюме модели.
- Локальные проверки ссылок и чисел не доказывают смысловую точность ответа.
- OCR сложных таблиц и ограниченный охват выборки требуют проверки по оригиналу.
- Локальные базы, документы, конфигурации и ключи не публикуются в репозитории.
