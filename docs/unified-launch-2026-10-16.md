# Единый локальный запуск

Основной проект: `~/Desktop/document-rag-vscode`.
В `~/Desktop/document-rag-vscode-1` обновлён запускатель `manage.py`:
он передаёт команды `bank`, `bank-backup`, `bank-restore` основной папке,
используя её Python и код. Остальные файлы второй папки не синхронизируются.

Из любой из этих двух папок:

```bash
.venv/bin/python manage.py bank
```

Интерфейс: http://127.0.0.1:8502, API: http://127.0.0.1:8766.
Повторный запуск при занятых портах не создаёт второй сервер.

В основной папке локальный `config.json` содержит:

```json
{"bank": {"database": "data/bank/unified.sqlite3"}}
```

Во второй папке поле `bank.workspace` содержит абсолютный путь к основной
папке. Это дополнительные поля существующих конфигураций, а не замена
настроек GigaChat. Конфигурации и базы не включаются в Git.
Переменная `BANK_DATABASE`, если задана вручную, переопределяет путь базы.

16 октября объединены три локальные базы: старая и актуальная базы основной
папки и база из `document-rag-vscode-1`. В объединённой базе на момент
переноса: 25 документов, 34 ответа и 17 диалогов. Проверено наличие всех
идентификаторов документов, ответов и диалогов из исходных баз, целостность
SQLite и внешние ключи. Поисковые производные данные перестроены.

Исходные базы сохранены. Согласованные резервные копии, прежние конфигурации,
запускатель второй папки и отчёт переноса находятся локально в
`data/backups/unify-final-20261016-134602/` основной папки.
Перед ручным восстановлением базы необходимо остановить сервер.
