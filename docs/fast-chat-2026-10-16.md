# Восстановление чата и суммаризации

В последних пользовательских запросах API GigaChat возвращал `finish_reason=blacklist`.
Это реальный отказ провайдера, а не результат локальной проверки ссылок.
Один из коротких вопросов использовал около 73 тысяч токенов контекста.
При этом интерфейс запрещал чат без документов, а промпт разрешал только
документальные ответы. После отказа найденные фрагменты скрывались.

Fast v6 сохраняет один запрос генерации и модельные ограничения контекста.
Вместо обязательного JSON запрашивается обычный текст с `[Qn]`-ссылками;
ссылки привязываются к реально переданным фрагментам. Совместимость с прежним
JSON-ответом сохранена. Общие ответы без цитат явно обозначаются, а вопросы
о документах не должны дополняться сведениями из памяти модели.

Для обычного вопроса используется компактный контекст. Для резюме — выборка
из начала, середины и конца активных версий, а не только совпадения с запросом.
Это резюме выборки, не гарантия полного прочтения каждого документа.
Много документов по-прежнему могут использовать большое окно модели.

Отказы фильтра и лимит длины не открывают circuit breaker для других вопросов.
При ошибке доступны найденные источники, отдельно от цитат ответа.
Если фильтр блокирует резюме, приложение показывает локальные выдержки с явным
обозначением отказа и происхождения результата. Автоматических повторов или
переключения модели для обхода отказа нет.

Живая проверка GigaChat-2:

- Вопрос о таблицах с мерами сегментации и межсетевого экранирования получил
  ответ со ссылками на таблицы 13 и 42; компактный контекст — около 20 тысяч токенов.
- Приветствие без документов получило естественный текстовый ответ.
- Вопрос о приготовлении пищи в ГОСТ Р 57580.1—2017 после исправления промпта
  получил сообщение об отсутствии такой информации в переданных источниках.
- Резюме пользовательского ГОСТа всё ещё блокировалось фильтром провайдера.
  Это открытое ограничение; локальная подборка выдержек не заменяет полноценное
  смысловое резюме модели.

Локальные регрессии проверяют обычный чат, ссылки, отсутствие поддельных цитат,
сохранение источников при отказе, охват начала и конца документа и маркировку
локального результата. Они не доказывают семантическую точность всех ответов.
