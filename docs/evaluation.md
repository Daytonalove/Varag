## GigaChat

Официальный v1 контракт сверён. Live smoke только с двумя учебными лимитами,
без документов пользователя: OAuth, model listing, TLS, JSON Schema, quote/ID
validator и обе ссылки проверены. Scope `GIGACHAT_API_PERS`;
model version `GigaChat-3-Pro:32.4.30.3`, total_tokens=141 последнего успешного вызова.
Первый ответ не прошёл валидатор; он не публиковался. Повторный отдельный запрос
успешен. Это показывает необходимость валидации, а не гарантированное качество LLM.

Mock: bounded 429/503 retry и circuit breaker, 422 без ложного успеха,
external policy, fabricated block/quote rejection. OAuth caching/TLS/401
покрываются существующим provider-набором; корпоративные GC-AT-01/02 всё ещё
не приняты из-за PERS. GC-AT-05 реализует честный отказ, но не multi-stage.
GC-AT-07 (полное осмысление исключения) остаётся незавершённым.

Реальные банковские метрики citation precision ≥98%, conflict recall ≥90%,
precision ≥85%, grounding ≥95% **не измерялись**. Нет согласованного корпуса
200 экспертно размеченных вопросов. Итог: пригодно для продолжения разработки,
не является актом приёмки MVP и не разрешает загрузку банковской тайны.
